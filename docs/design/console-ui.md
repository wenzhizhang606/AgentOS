# AgentOS 控制台界面设计

适用于 REQ-OBS-001、TASK-009、AC-013 与 AC-023。项目观察者登录一次，即可核对项目的运行情况、一次具体执行以及当前发布包含的能力。

## 三个视图回答三个问题

| 观察者的问题 | 进入位置 | 核对方式 |
| --- | --- | --- |
| 这个项目执行了多少任务，调用了哪些能力？ | 项目概览 | 先读时间窗口和主要指标，再看状态分布、Skill、Tool、模型调用与最近任务。展开更多指标可核对费用等明细。 |
| 这次运行经过了哪些环节，慢在哪一步？ | 最近任务 → 任务时间线 → 某次领取对应的轨迹，或直接输入运行 ID | 以“任务 ID + 尝试号”识别实例，先看瀑布图，再按事件核对时间、能力摘要、模型准入和回执。重试有独立入口。 |
| 当前发布装了哪个版本的 Skill 或 Tool？ | 资源管理 → 名称搜索 / 类型筛选 → 资源名称 | 在详情中核对名称、类型、版本和完整 SHA-256。在列表中改变筛选时，发布总数保持原值。 |

## 组件与视觉约定

公开主页（`/console`）采用 B 方案的建筑横幅，主操作「进入控制台」打开登录页（`/console#login`）。主页展示可进入的功能，首次访问只读取公开页面与图片。

工作区入口之后展示 Agent 组成图和运行示例。访问者可选择问题、播放或逐步阅读，图中同步标出执行当前步骤的组件。桌面上可以对照图和步骤，窄屏按阅读顺序排列。示例使用本地固定内容，播放状态仅存在于页面，切到其他视图或浏览器标签会暂停。真实项目轨迹仍从授权后的运行视图读取。[组成图](../../src/agentos/observability/agent-components.svg) · [示例交互](../../src/agentos/observability/walkthrough.js)

登录页采用 A 方案，桌面左侧是深色执行架构图，右侧填写项目 ID 和访问令牌，手机优先展示表单。从轨迹或资源书签登录会进入对应视图，常规登录进入项目概览。提交时就地提示正在验证，成功后将焦点移到工作区标题。令牌过期或无权读取时清除令牌和项目数据，在表单说明原因。首次遇到服务故障可用表单内的原输入重试。已进入项目的观察者遇到临时读取错误，可直接刷新。工作区的“更新于”记录浏览器最近一次成功读取数据的时间。

点击 AgentOS 品牌可返回主页，已验证的观察者可在同一页面重新进入工作区。「退出项目」清除本页凭证并返回主页。顶栏承载当前项目和三个一级视图，时间范围与刷新放在当前视图内。以留白、标题层级、细分隔线组织指标、图表和表格，红色用于主操作及选中态。窄屏将导航换行，长表在自己的容器内滚动。状态同时提供文字或数字。设计取舍与一手资料见[企业控制台调研](../research/enterprise-console-design.md)。

| 复用单元 | 应用位置 | 行为 |
| --- | --- | --- |
| 指标与属性列表 | 概览总量、运行详情 | 使用名称和值组成的语义化列表。计数为零时显示 0，缺失值显示“—”。费用按微元格式化，Token 与大整数保留精度。 |
| 状态标签 | 最近任务、实例与费用状态 | 使用一致的状态文字与样式。任务失败可进一步查看错误码。 |
| 表格行操作与空态 | 任务、实例、资源和事件 | 可操作值使用原生按钮，支持 Tab、Enter 和空格。空态写明当前集合，搜索无结果时允许清除条件。 |
| 资源详情 | Skill 与 Tool | 点击名称后将焦点交给详情，Escape 或关闭按钮返回。刷新以最新发布清单为准。 |
| 标识与复制操作 | 资源详情的 SHA-256、单次运行 ID | 显示完整值，键盘或鼠标均可复制。浏览器限制剪贴板写入时，选中文本并提示手动复制。 |
| 调用瀑布图 | 单次尝试 | 时间轴按真实事件定位，缺少开头或结尾时显示对应文字。下方表格保留精确数值和关联标识。 |

## 新增视图时如何接入

1. 在 [dashboard.html](../../src/agentos/observability/dashboard.html) 声明语义化页面骨架、控件标签和视图容器。
2. 从 [components.js](../../src/agentos/observability/components.js) 复用指标、状态、表格操作和空态。在 [console.js](../../src/agentos/observability/console.js) 处理项目范围、API 请求和视图切换。接口返回的文本通过 DOM 文本节点呈现。
3. 在 [console.css](../../src/agentos/observability/console.css) 使用统一的颜色、间距、焦点和窄屏规则。图表配套文字读数，宽表在容器内滚动。
4. 在 [浏览器契约测试](../../tests/contracts/test_monitor_dashboard.py) 覆盖正常数据、空数据、退出项目、撤权与迟到响应。手工检查桌面及 320 像素宽视口，检查长名称、全长摘要、键盘导航和焦点返回。

[页面装配模块](../../src/agentos/observability/page.py) 从同一 Python 安装包读取界面资源。HTML 内嵌控制台脚本和样式，主页照片从同源的公共图片地址加载。页面可以复用，项目数据与凭证只存在于当前页的连接中。关页、断开或鉴权失败后需要重新连接。
