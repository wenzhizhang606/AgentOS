# AgentOS 控制台界面设计

适用于 REQ-OBS-001、TASK-009、AC-013 与 AC-023。项目观察者登录一次，即可核对项目的运行情况、一次具体执行以及当前发布包含的能力。

## 三个视图回答三个问题

| 观察者的问题 | 进入位置 | 核对方式 |
| --- | --- | --- |
| 这个项目执行了多少任务，调用了哪些能力？ | 项目概览 | 先读时间窗口和主要指标，再看状态分布、Skill、Tool、模型调用与最近任务。展开更多指标可核对费用等明细。 |
| 这次运行经过了哪些环节，慢在哪一步？ | 最近任务 → 任务时间线 → 某次领取对应的轨迹，或直接输入运行 ID | 以“任务 ID + 尝试号”识别实例，先看瀑布图，再按事件核对时间、能力摘要、模型准入和回执。重试有独立入口。 |
| 当前发布装了哪个版本的 Skill 或 Tool？ | 资源管理 → 名称搜索 / 类型筛选 → 资源名称 | 在详情中核对名称、类型、版本和完整 SHA-256。在列表中改变筛选时，发布总数保持原值。 |

## 组件与视觉约定

桌面使用固定位置的工作区导航，页面标题与工具栏标明所在视图和项目。窄屏将导航收拢到页面上方，表格在自己的容器内横向滚动。红色用于主要操作、当前导航和重点，正文、分隔和次要控件使用中性色。所有状态同时给出文字或数字，图例标明每一种颜色的含义。信息层级参考华为云控制台导航，搜索控件参考 OpenTiny 对搜索、过滤及清除的交互划分。[华为云控制台公共导航](https://support.huaweicloud.com/qs-consolehome/consolehome_qs_0003.html) · [OpenTiny 搜索组件](https://opentiny.design/tiny-vue/zh-CN/smb-theme/components/search)

| 复用单元 | 应用位置 | 行为 |
| --- | --- | --- |
| 指标与属性列表 | 概览总量、运行详情 | 使用名称和值组成的语义化列表。计数为零时显示 0，缺失值显示“—”。费用按微元格式化，Token 与大整数保留精度。 |
| 状态标签 | 最近任务、实例与费用状态 | 使用一致的状态文字与样式。任务失败可进一步查看错误码。 |
| 表格行操作与空态 | 任务、实例、资源和事件 | 可操作值使用原生按钮，支持 Tab、Enter 和空格。空态写明当前集合，搜索无结果时允许清除条件。 |
| 资源详情 | Skill 与 Tool | 点击名称后将焦点交给详情，Escape 或关闭按钮返回。完整摘要可选中复制。刷新以最新发布清单为准。 |
| 调用瀑布图 | 单次尝试 | 时间轴按真实事件定位，缺少开头或结尾时显示对应文字。下方表格保留精确数值和关联标识。 |

## 新增视图时如何接入

1. 在 [dashboard.html](../../src/agentos/observability/dashboard.html) 声明语义化页面骨架、控件标签和视图容器。
2. 从 [components.js](../../src/agentos/observability/components.js) 复用指标、状态、表格操作和空态。在 [console.js](../../src/agentos/observability/console.js) 处理项目范围、API 请求和视图切换。接口返回的文本通过 DOM 文本节点呈现。
3. 在 [console.css](../../src/agentos/observability/console.css) 使用统一的颜色、间距、焦点和窄屏规则。图表配套文字读数，宽表在容器内滚动。
4. 在 [浏览器契约测试](../../tests/contracts/test_monitor_dashboard.py) 覆盖正常数据、空数据、断开连接、撤权与迟到响应。手工检查桌面及 320 像素宽视口，检查长名称、全长摘要、键盘导航和焦点返回。

[页面装配模块](../../src/agentos/observability/page.py) 从同一 Python 安装包读取界面资源，随 API 返回一个同源页面。页面可以复用，项目数据与凭证只存在于当前页的连接中。关页、断开或鉴权失败后需要重新连接。
